米兔教室座位系統 PWA 快取修正版
版本：v2026.04.30-60

這版修正重點：
1. 修掉舊版 service worker 一直把 index.html 從快取吐回來的問題。
2. HTML / manifest / icons 改成 network-first，重新整理時會優先抓 GitHub Pages 上的新檔案。
3. service worker 註冊加入 updateViaCache:none 與版本參數。
4. 新增 clear-cache.html，可用來清除舊版 PWA 快取。
5. 桌面圖示維持透明背景與放大版兔兔。

上傳 GitHub Pages 後，請第一次先打開：
https://你的帳號.github.io/你的repo/clear-cache.html

它會自動：
- 移除舊 service worker
- 清除舊 cache
- 跳到 index.html?v=60

之後正常使用網址：
https://你的帳號.github.io/你的repo/
或
https://你的帳號.github.io/你的repo/index.html?v=60

手機 Chrome 如果仍看到舊版：
1. 先開 clear-cache.html
2. 刪掉主畫面上的舊捷徑 / 舊 PWA
3. 重新加入主畫面

資料提醒：
清除 PWA 快取通常不會清 localStorage，但正式更新前仍建議先在系統內「匯出佈置」與「匯出名單」。
